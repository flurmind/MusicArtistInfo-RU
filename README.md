# Плагин Music And Artist Information для экосистемы Squeezebox (RU fork)

Этот плагин для Logitech Media Server (LMS) и экосистемы Squeezebox предоставляет дополнительную информацию о вашей музыкальной коллекции: биографии исполнителей, обзоры альбомов, сведения об участниках записи, похожих артистах и многое другое.

Это неофициальный форк оригинального плагина [MusicArtistInfo](https://github.com/michaelherger/MusicArtistInfo) от Michael Herger, дополненный поддержкой русского языка.

Информация, отображаемая плагином, запрашивается из следующих источников:
* [Wikipedia](https://wikipedia.org)
* [Last.fm](https://last.fm)
* [Discogs](https://discogs.com)
* [MusicBrainz](https://musicbrainz.org)

### Особенности форка

- **Поддержка русского языка:** Добавлен RU, приоритет русского сегмента Wikipedia/Last.fm с fallback на английский.
- **Умный поиск в Wikipedia:** 3-ступенчатый алгоритм (прямой поиск → фильтр дизамбигов → полнотекстовый поиск с проверкой упоминания артиста).
- **Исправление Wikidata:** Обход принудительной английской pageid — сначала поиск по имени в русской Википедии.
- **Приоритет локальной лирики:** Локальный поиск в первую очередь, поддержка файлов `Артист - Название.lrc/txt`.

## Установка

Плагин устанавливается через встроенный менеджер плагинов LMS — как обычный сторонний плагин, без ручной работы с файлами.

1. В LMS откройте **Settings → Plugins**, прокрутите вниз до раздела **Additional Repositories**.
2. Добавьте ссылку:
```Bash
   https://raw.githubusercontent.com/flurmind/MusicArtistInfo-RU/master/repo.xml
```
3. Нажмите **Save**.
4. В списке плагинов появится **Music Artist Information (RU fork)** — включите его.
5. Перезапустите LMS Server (кнопка **Restart Server** там же, в Settings → Plugins).
> **Примечание:** этот форк использует тот же идентификатор плагина, что и оригинал, и имеет более высокий номер версии. LMS автоматически предложит его вместо официальной версии после добавления репозитория — отключать официальный источник не обязательно.

### Обновление

При выходе новой версии форка LMS предложит обновление автоматически через тот же механизм Additional Repositories — как и с любым другим плагином.
